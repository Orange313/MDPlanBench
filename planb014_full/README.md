# Economics and mechanism replay extension

Recovered unchanged from the previously audited 015 review candidate; original README is in docs/history/README_015_extension_original.md. MIT now applies to original software only; the historical claim that no MIT grant exists is superseded by root LICENSE. This new candidate remains LOCAL REVIEW ONLY, not newly published.

Use scripts/reproduce_with_official_annotations.py with explicit upstream-terms acknowledgment to recompute all18 mechanism CSVs and the Economics summaries from pinned official Biomedical/Economics queries/qrels. No sealed project labels, page images or pretrained weights are read by this CPU command. Original source questions, full qrels and case prose are acquired into a user-owned cache outside Git and are not redistributed.

Full Economics hardware preparation is available in prepare_economics_workspace.py; it has not been GPU-validated in this task. Its archive status is historical-design reproduction, not new preregistration.
