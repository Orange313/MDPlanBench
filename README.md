# MDPlanBench / MDRouter — ICDE 2027 EAB artifact

MDPlanBench evaluates the quality, risk and complete-path cost of physical
execution plans and fixed query-routing policies for multimodal document retrieval.

**Paper:** *[Experiment, Analysis, and Benchmark] MDPlanBench: When Does
Query-Level Physical Plan Selection Pay Off for Multimodal Document Retrieval?*

**Release:** [icde27-eab-v1.1](https://github.com/Orange313/MDRouter/tree/icde27-eab-v1.1).
For detailed provenance and interpretation, see [the reproduction guide](README_EAB_V1.md).

## CPU reproduction

Use Linux with Python 3.11 and install `env/requirements-cpu-lock.txt` in a virtual
environment. Then reproduce the paper's numerical tables and figures with one command:

```bash
python scripts/reproduce_paper.py --output /absolute/path/NEW_OUTPUT
```

The output directory must not exist. Replay takes about 40–45 seconds on the
reference host after installation and needs no GPU, network, weights or original
dataset files. It checks 42 historical CSVs, produces 14 paper/analysis table
outputs and reconstructs the figures. Actual hardware timings are archived
measurements; replay does not remeasure them.

## Known limitations and verification

- Development and post-hoc analyses are exploratory. No new risk certificate
  or reliable Serving speedup is claimed; repeated timings are not independent queries.
- Economics has one relevance-connected source component, so its intervals are
  conditional. Its archived intervals use a fixed FullV mean as denominator.
- The original policy comparison uses a four-static-plan envelope; capacity and
  accounting controls use three actions: FullV, BM-100 and BM25. Keep them separate.
- Setup and warm measurements from different cohorts are not subtracted.
  Pretraining overlap is unknown; the RR-adapted baseline is not the official RetrievalRouter.
- Linux is the byte-comparison reference. Windows can produce last-digit float
  differences; the archived failure and its numerical bounds are retained.

The historical R69 audit is retained unchanged in `ledger/`. Paper R70 corrected
the calibration source count to 20, removed the misidentified Dev-family counts,
rounded the learning-curve risk to 0.056, used 10.9–14.5% for warm savings, and
clarified the fixed FullV denominator for Economics intervals.

The actual anonymous public-clone and Linux replay receipt is
[`validation/task31/anonymous_clone_and_replay.json`](validation/task31/anonymous_clone_and_replay.json);
