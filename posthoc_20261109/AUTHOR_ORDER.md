## 2. 登记参数（PLAN.md 原样写入）

### 2.1 共同对象

- 检索器：ColQwen2。
- 语料 c ∈ {HR, Finance, Industrial, Pharmaceuticals（仅 dev split，45 题）, Biomedical（160 题）, Economics（58 题）}。
- 动作集 A = {FullV, BM-100, BM25}（三动作）。
- Router ρ ∈ {ridge-Q, ridge-QP, LightGBM-Q, LightGBM-QP}，取自 post-hoc 批次。模型权重与特征预处理冻结，只重选 κ。
- 质量：nDCG@10（线性增益）；regret r_a(q) = max{nDCG(FullV, q) − nDCG(a, q), 0}。
- 成本：s_a(q, m) 为查询 q 在进程 m 中动作 a 的匹配静态路径成本（post-hoc 批次实测，按进程保留）；o_ρ(q, m) 为 router ρ 的决策开销（特征、预测，以及 QP 的探针）。QP 选择 BM-100 时复用探针候选，不得重复计费。组合规则**完全复用 Fig. 5(b) 会计分解的现有代码**。

### 2.2 回归闸门（先于一切 E2 计算）

在 κ=20 下，用适配任意动作数组后的新入口重算：Fig. 5(b) 的三项分解及四个 router 在六个语料上的 ΔC，必须与现有结果**逐位一致**。任何一项不一致即停止 E1/E2，报告差异表。

### 2.3 折划分

- K = 5，按组划分：开发域与 Economics 按问题族分组；Biomedical 按来源讲座分组（27 个）。
- 分配方法：组按 ID 排序，用种子打乱后，依次放入当前查询数最少的折（贪心平衡）。
- 主种子：20261109。稳定性检查种子：1, 2, 3, 4, 5。
- 记折 k 的留出集为 H_k，训练集为 T_k = Q_c \ H_k。

### 2.4 网格

- 风险预算 b ∈ {0.01, 0.02, 0.03, 0.05, 0.075, 0.10}。主报告点 b = 0.05。
- κ ∈ {0, 1, 2, 5, 10, 20, 40, 80, 160, 320, ∞}。
  - 一般情形：a_{ρ,κ}(q) = argmin_a { ĉ_a + κ · max(r̂_{ρ,a}(q), 0) }，ĉ_a 与 r̂ 的定义、归一化方式和平局规则沿用冻结代码（与论文 Eq.(7) 一致），并在 PLAN.md 中写明。
  - κ = 0：取 argmin ĉ_a（即 BM25）。
  - κ = ∞：**定义为全部走 FullV**，不按预测 regret 取 argmin。

### 2.5 κ 选择规则（每折、每个 b）

κ*_{k,b} = 在 T_k 上满足 mean_{q∈T_k} r(q | κ) ≤ b 的 κ 中，mean_{q∈T_k} C_{ρ,κ}(q) 最小者。
其中 C_{ρ,κ}(q) 为跨进程平均的组合成本。κ = ∞ 始终可行（regret 为 0），因此总有解。若成本并列，取较大的 κ。

### 2.6 Mixture（每折、每个 b）

在 T_k 上计算各动作的平均 regret r̄_a^T 与平均成本 C̄_a^T，求解

min_w Σ_a w_a C̄_a^T s.t. Σ_a w_a r̄_a^T ≤ b，Σ_a w_a = 1，w ≥ 0，

得到权重 w^{(k,b)}。在 H_k 上按期望计算：R_mix(k,b) = Σ_a w_a · mean_{q∈H_k} r_a(q)，C_mix(k,b) 同理。主结果用期望值；另按固定种子实际抽样执行一次，作为次要结果。

### 2.7 OOF 汇总与 ΔC_cf 定义

1. Router：R_ρ^OOF(b) = (1/|Q_c|) Σ_k Σ_{q∈H_k} r(q | κ*_{k,b})；C_ρ^OOF(b) 同理（成本取跨进程平均）。
2. Mixture：R_mix^OOF(b) 与 C_mix^OOF(b) 为各折结果按 |H_k| 加权的平均。
3. Cross-fitted 前沿 H(·)：取点集 { (R_mix^OOF(b), C_mix^OOF(b)) : b ∈ 网格 } ∪ { FullV 点 (0, C̄_FullV)，BM25 点 (r̄_BM25, C̄_BM25) }，其中 FullV、BM25 点为全语料均值（静态计划无需拟合）。取其下凸包，在 [0, r̄_BM25] 上分段线性插值；风险超过 r̄_BM25 时 H = C̄_BM25。
4. **定义**：
   ΔC_cf(ρ, b) = 100 × [ H(R_ρ^OOF(b)) − C_ρ^OOF(b) ] / C̄_FullV，单位 pp。
   C̄_FullV 为该语料在 post-hoc 批次中的 FullV 平均成本。正值表示 router 在相同实现风险下比 cross-fitted mixture 便宜。
5. **冻结参照**：κ = 20（不做选择）在同一框架下的 ΔC_cf(ρ, κ=20) = 100 × [ H(R_ρ(κ=20)) − C_ρ(κ=20) ] / C̄_FullV。

### 2.8 区间与稳定性

- 主种子下固定折划分、固定已拟合的 κ*_{k,b} 与 w^{(k,b)}，按 §0.3 的单元做 2,000 次配对 bootstrap，每次重算 OOF 汇总、H 与 ΔC_cf。区间注明"conditional on fitted κ and weights"。
- 用种子 1–5 各重做一次折划分与拟合，报告 ΔC_cf 点估计的范围和所选 κ 的分布。

### 2.9 条件实测

只有当某个格子（语料 × router，b = 0.05）的 ΔC_cf 95% 区间**完全大于零**时，才对该组合（所选 κ）在 resident harness 中按原计时协议实测一次：3 进程 × 3 次重复，单次不超过 1 小时 GPU，需要独占卡并在 ResourceGuard 下运行。其余格子不实测。未预约到 GPU 则记 NOT_RUN 并在汇总中标明。

## 3. 各实验定义

### E1｜Retrospective envelope 的乐观偏差

- 风险点 r ∈ {0.01, 0.02, 0.03, 0.05, 0.075, 0.10} ∩ [0, r̄_BM25]。
- Bias(r) = 100 × [ C_env^retro(r) − H(r) ] / C̄_FullV，单位 pp。负值表示 retrospective envelope 比 cross-fitted 前沿更便宜，即偏乐观。
- 两套计算：
  - **post-hoc 批次**：三动作，H 即 §2.7 的前沿。
  - **主批次**：四个静态计划（FullV、BM-50、BM-100、BM25），C_env^retro 为论文 Eq.(3) 的 envelope；H 用同样的折划分与 §2.6 的 LP 在四个静态计划上重做，成本只用主批次。
- 输出：每个语料 Bias 的中位数与最大绝对值，两套各一行。

### E2｜目标语料重选 κ 后的比较

按 §2.2–§2.9 计算。输出每个语料 × router：
- b = 0.05 时的 R_ρ^OOF、C_ρ^OOF（ms 与 % FullV）、ΔC_cf [95% 区间]、种子 1–5 的点估计范围、各折所选 κ；
- 全部 b 的同一组数值（附表）；
- 冻结 κ = 20 的 ΔC_cf [95% 区间]。

### K17｜κ = 20 学习曲线重算

- Pharmaceuticals，ridge 容量固定，训练规模、子集与种子与原学习曲线完全相同，评估与成本口径与原诊断相同，κ 改为 20。

- 在 RESULTS_SUMMARY 中如实写明：κ = 10 与 κ = 20 来自同一轮七点网格开发，当时选择 κ = 10 的理由未登记。不得表述为"冻结前诊断"。

### E3｜可检测边界

- 对象：主实验 12 个格子（4 个开发域 × {Q, QP}，加 Biomedical 与 Economics × {Q, QP}）；post-hoc 24 个格子（6 语料 × 4 router）。

- 本轮保存抽样索引与逐次 ΔC。
- 输出每个格子的 95% 区间下端 L 与上端 U，以及 U < 5、< 10、< 15 pp 的格子计数。

### E4｜Router 与 transferred mixture

- 只用 post-hoc 批次中**同批实测**的三点：FullV、Fit-only 0.05 mixture、BM25（实现风险与实测成本），构造下凸包 C_tr(·)，标注"粗凸包"。0.02 与 0.10 不使用重组估算。
- 对四个 router 在冻结 κ = 20 下：ΔC_tr = 100 × [ C_tr(R_ρ) − C_ρ ] / C̄_FullV，按 §0.3 做 bootstrap。
- 优先级最低（CPU 部分）。时间不足记 NOT_RUN。

### E5｜OCR 并行计时

- 输入：Biomedical 1,016 页页面图像。Tesseract 4.1.1，eng，psm 3，其余参数与冻结配置完全一致。
- worker 档位 ∈ {1, 2, 4, 8, 16}，每档重复 3 次。执行顺序：按重复轮次外层循环，每轮内用种子 20261109 打乱档位顺序。
- 每个 worker 进程设置 OMP_THREAD_LIMIT=1。记录 wall time 与 CPU 秒（子进程 user + sys）。
- 磁盘：每档只保留一份 OCR 文本加逐页哈希，其余重复只记计时；临时目录用完即清。总预算 ≤ 1 GB，开跑前核定可用空间。
- **闸门**：输出文本与冻结 OCR 文本逐页比较哈希。不一致时报告不一致的页数，不得用新文本替换旧文本。
- 用论文的生命周期组合脚本（同进程 setup 与 warm 配对），分别以 wall time 与 CPU 秒作为 OCR 成本，重算两种检索器的 crossing N*。场景：OCR 独占、OCR 承担一半、OCR 已预付。报告各档位、各场景、三个进程上的范围。
- 补答：Biomedical 原 407.7 s 的 worker 数与线程设置。

### E6｜FullV 两倍延迟差异定位（条件执行）

- 仅在作者预约到独占 GPU 时执行。开跑前做三次空闲检查，全程在 ResourceGuard 下运行，复用现有 embedding，不重建索引。
- Biomedical + ColQwen2 的 FullV，在同一进程中交替执行两种调度，ABAB 分块，每块 160 个查询：
  - 调度 A：九方法交错，每查询计时 3 次（复现主批次调度）；
  - 调度 B：四静态计划，每查询计时 1 次（复现 setup 研究调度）。
- 同时以 1 秒间隔记录 nvidia-smi 的 SM/显存频率、温度、功耗。
- 输出两种调度下 FullV 的平均延迟及差异，判断是否复现 70.22 ms 对 36.22 ms，以及频率或温度是否随调度同步变化。总时长 ≤ 2 小时。未预约到 GPU 则记 NOT_RUN。

### E7｜文本来源对照（HR，条件执行）

- 只使用 HR 上已有全页分数覆盖的查询，不补采任何新的全量排名。先报告覆盖查询数及其占 HR 查询的比例；覆盖率 < 50% 则记 NOT_RUN。
- 对 HR 1,110 页用与 V2 完全相同的 Tesseract 配置做 OCR，BM25 参数不变（k1 = 1.5，b = 0.75）。
- 按 shared-scorer 不变式离线计算 BM-100 的 top-10（FullV 排序限制在 BM25 前 100 候选内取前 10），得到 BM-100 与 BM25 的 mean regret 与 harm rate，与官方 markdown 版本对比。

### E8｜资产存储量

- 统计 11 个格子（6 语料 × 2 检索器，Economics × ColPali 登记为缺失，不补建）的实际磁盘占用：页面 embedding（fp16）、BM25 倒排索引、OCR 或 markdown 文本。
- 用"页数 × 每页实际 patch 数均值 × 维度 × 2 字节"做解析核对。
- 输出 MB 数，以及视觉资产 / BM25 资产的比值。
