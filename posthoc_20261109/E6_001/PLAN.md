## 2. 登记参数（作者原文）

### 2.1 四种调度（2×2）
| 代号 | 交错的方法组合 | 每个方法每查询计时次数 | 说明 |
|---|---|---|---|
| A | 九方法 | 3 | 复现主实验 |
| B | 四静态计划 | 1 | 复现 setup 研究 |
| A1 | 九方法 | 1 | 拆分：只改计时次数 |
| B3 | 四静态计划 | 3 | 拆分：只改方法组合 |

- 九方法与四静态计划的组成、查询内执行顺序，与原两次运行完全相同。
- 计时 3 次时，三次全部记录，并标注重复序号（1/2/3），分析时同时报告三次平均与仅第 1 次。

### 2.2 块设计
- 查询：Biomedical 全部 160 个查询，每块按固定种子打乱顺序（种子 20261109 + 块号）。
- 同一进程内依次执行 8 个块，顺序为 A, B, A1, B3, B3, A1, B, A（ABBA 式平衡，消除时间漂移）。
- 进程启动后先做 20 个查询的预热（不计入），之后不再重启进程。
- 如时间不足，优先保证 A 与 B 各两块完成；A1、B3 未完成记 PARTIAL。

### 2.3 指标
- 主指标：每个调度下 FullV 的平均暖态延迟（ms），以查询为单位先在块内平均，再在同调度的两块间平均。
- 区间：以查询为重采样单元、块内配对的 bootstrap，2,000 次，种子 20261109。
- 报告：
  1. A − B 的差值与 95% 区间；与原差值 34.0 ms（70.22 − 36.22）比较。
  2. 主效应：方法组合效应 = [(A + A1) − (B + B3)] / 2；计时次数效应 = [(A + B3) − (A1 + B)] / 2；交互项 = (A − A1) − (B3 − B)。各附 95% 区间。
  3. 计时 3 次时，第 1 次与第 2、3 次的延迟差（检验"首次较慢/后续较快"）。
  4. 各块的平均 SM 时钟、温度、功耗，以及它们与块均值延迟的对应关系。
- 复现判定（预先登记）：A − B 的 95% 区间下界 ≥ 17 ms（即原差值的一半）记为"复现"；区间包含 0 记为"未复现"；介于两者之间记为"部分复现"。
