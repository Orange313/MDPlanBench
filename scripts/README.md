# Executable entry points
`reproduce_submission.py`: full offline current-manuscript numerical replay.
`reproduce_paper.py`: preserved earlier artifact replay.
`verify_paper_values.py`: compare extracted manuscript numeric cells/key claims.
`verify_manifest.py`: file integrity.
`acquire_assets.py`: pinned official download plan, individual fetch and verification.
`check_upstream.py`: endpoint/terms metadata audit; never a legal clearance.
`full_reproduction.py`: explicit from-scratch asset/dependency plan and CPU preflight.
Original algorithms remain in `repro/`; original hardware workers in
`execution_source/` and `source_archive/`. Archive existence is not execution evidence.
Do not run archival train/prepare/orchestration code indiscriminately.
