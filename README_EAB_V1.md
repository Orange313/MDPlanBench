# MDPlanBench / MDRouter — ICDE 2027 EAB artifact

This branch extends public main `e971def8` without rewriting it. The artifact
supports a study of physical execution plans, the value/cost of routing signals,
and lifecycle cost. It does **not** claim a new K1 certificate or a Serving speedup.
Negative results, conditional intervals, historical failures, and audit issues
are retained. The manuscript itself is maintained separately and is not edited
by these scripts.

## One-command CPU reproduction after environment setup

Linux is the reference platform. The historical GPU environment is Python
3.11.15, PyTorch 2.5.1+cu121, CUDA 12.1, NVIDIA driver 570.133.20, RTX A6000
48 GiB. CPU replay requires no GPU, network, model weights, raw images, queries,
qrels, OCR documents, or sealed files. Allow about 1 GiB for Python dependencies
and scratch output. The measured preflight runtime is about 40 seconds on the
experiment server; runtimes vary by host.

```bash
python3.11 -m venv .venv-replay
. .venv-replay/bin/activate
python -m pip install -r env/requirements-cpu-lock.txt
python scripts/reproduce_paper.py --output /absolute/path/NEW_OUTPUT
```

The output path must not exist. Logs, numerical tables, PNG/PDF figures, and a
machine-readable receipt are written there. A failure never overwrites an older
attempt. Existing `reproduce_all.py` remains the historical 42-table entry point.
On Windows two historical CSV hashes differ because floating-point accumulation
changes the last few digits (78 cells; maximum absolute delta recorded in the
validation receipt); this is preserved as a platform limitation. Use Linux for the byte
comparison gate rather than silently replacing expected hashes.

## Data and model acquisition / GPU execution

Read `data/README.md` and the third-party notices before obtaining official
assets. Pinned revisions, SHA256, and acquisition recipes are in `config/`,
`freeze/`, and `acquire_public_assets.py`. Official V2 biomedical and economics
assets must be downloaded by the reproducer under their own applicable terms.
Do not redistribute textbook pages, original PDFs/images, full qrels, private
question examples, model weights, or proprietary assets through this repository.

The original GPU execution sources and four-plan smoke are retained in
`execution_source/` and `minimal_gpu_sample.py`. The smoke requires explicit
official asset paths and an actually idle GPU, checks idleness three times, and
uses ResourceGuard throughout. It verifies a small 16-page sample; it is **not**
a fresh full benchmark run. Task31 ran a predeclared HR Dev query (ID 0), with
an explicit V3 field-name adapter, on GPU3. Its receipt is in `validation/task31/`.
An additional full HR validation ran all 40 frozen Dev queries over 1,110 pages,
four static plans, one process and three repetitions (480 requests) on idle GPU5.
All 160 Top-10 lists and quality metrics matched exactly. Absolute times were
about half those of the archived process, which is retained as a cohort/hardware
measurement limitation, not substituted into the paper. Its original public
source, input-read audit and new raw request/guard records are separately kept
under `validation/task31/full_HR_reproduction_001/`.
Full reruns require the historical dependency lock, model download/acceptance,
indexes, and sufficient storage; the current CPU checkout does not manufacture
fresh hardware measurements from numerical records.

## Information boundaries and statistical interpretation

The original policy comparisons use a four-static-plan envelope; 021 post-hoc
controls use FullV/BM-100/BM25. Do not mix them. All exploratory allocations and
oracles are descriptive. Routers are fixed; no model fitting occurs during replay.
Translations and repeated timings do not increase independent query counts.

Development intervals resample query families and processes. Biomedical uses
27 source lectures and processes. Economics has 58 questions / 53 candidate
families but **one** relevance-connected source component; intervals are
conditional, not source-population guarantees. Historical Economics Figure4
intervals normalize archived paired-ms intervals by fixed FullV mean; paired-
ratio sensitivity is separately retained. This differs from a blanket claim
that every denominator was resampled. The number ledger flags that wording issue.

Task31 found Fit/Cal family disjointness but 19 overlapping Pharma source
components (Fit21, Cal20, whole-domain23). Fixed-corpus query generalization
allows shared documents; document generalization and IID calibration are not
established. Cal/Eval and historical sealed label sets are not included.
